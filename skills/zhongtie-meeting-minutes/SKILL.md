# 中铁建工会议纪要撰写规范

## 1. 适用范围

用于把会议录音转写稿（可含口语、重复、错别字、多人抢话）整理为正式会议纪要。产出是**供内部流转的纪要**，不是新闻稿、不是讲话稿、不是会议记录。

不适用：对外新闻发布、合同文本、法律意见书、人事任免正式文件。遇到这类需求，只输出纪要，并提示另行办理。

## 2. 纪要体例（七段式）

除非用户另有要求，严格按以下顺序输出 Markdown：

### 2.1 标题

- 例行会议：`<单位/会议名称>会议纪要`，如 `中铁建工集团某工程局2026年三季度安全生产工作会议纪要`
- 专题会议：`关于<事项>的会议纪要`
- 党委会、董事会：`<公司名称>党委会会议纪要` / `<公司名称>董事会会议纪要`
- 标题不加书名号，不用"隆重召开""圆满举行"等新闻语。

### 2.2 会议基本情况

用"会议时间 / 会议地点 / 会议形式 / 主持人 / 参会人员 / 列席人员 / 记录人 / 会议议题"逐项列出。信息缺失写"（待补）"，**不得猜测**。

示例：

```
**会议时间**：2026年11月11日（星期三）下午14:30
**会议地点**：集团公司总部三楼会议室
**会议形式**：现场会议
**主持人**：XXX（职务）
**参会人员**：XXX、XXX、XXX
**列席人员**：XXX、XXX
**记录人**：XXX
**会议议题**：听取三季度安全生产工作情况汇报，研究部署四季度重点工作
```

### 2.3 会议听取和审议情况

按议题分节（`### 一、……`），每节写清：

1. 谁汇报/谁说明（单位、职务、姓名，缺一不可时才用"有关负责同志"）；
2. 汇报的核心内容（3–6 句，保留关键数据、问题、风险）；
3. 参会人员讨论的主要意见（有分歧的要如实写出"有的同志提出……"）。

不要逐句复述发言，不要写"某某总说""大家讨论得很热烈"。

### 2.4 会议决定事项

这是纪要的核心。逐条编号，每条包含"决定内容 + 责任单位 + 责任人 + 完成时限"。

```
1. 原则同意《XXX方案》，由XX部牵头，根据会议意见修改完善后，于2026年11月20日前报集团公司审批。
2. 同意成立XXX工作专班，由XXX任组长，XX部、XX部为成员单位，办公室设在XX部。
```

- 只有会议明确"同意/原则同意/通过"的事项才写"同意"；只是"听取汇报"的，写"会议听取了……汇报"，不得拔高为决议。
- 对未形成一致意见的事项，写"会议认为该事项还需进一步论证，责成XX部补充材料后另行研究"，不得写成已决定。
- 涉及"三重一大"的，注明决策程序（见第 4 节）。

### 2.5 会议要求

用"会议强调 / 会议要求 / 会议指出"分条写，聚焦责任、节点、底线要求。每条一事，避免空话套话堆砌。可引用集团年度工作会、安全生产会等公开精神，但不得编造具体文号或讲话原文。

### 2.6 督办落实（可选）

明确督办部门、督办方式、反馈节点。无明确要求时可省略。

### 2.7 分送、抄送（可选）

按用户提供范围写；未提供则不写，不得猜测收文单位。

## 3. 语言规范

### 3.1 基本要求

- 第三人称客观叙述，统一用"会议"作主语。
- 使用规范书面语，去掉口语词、语气词、重复、脏话、人身评价。
- 时态用"听取了""审议了""同意了""要求"。
- 数字、金额、比例、日期用阿拉伯数字；计量单位用法定单位（米、公里、平方米、亿元）。
- 人名首次出现写"姓名（职务）"，后文只写姓名；职务不明写"（待核）"。
- 单位名称首次用全称，后文可用规范简称；不得生造简称。

### 3.2 常用句式

| 场景 | 规范表述 |
| --- | --- |
| 听取汇报 | 会议听取了XX单位关于XX工作的汇报 |
| 审议文件 | 会议审议了《XX》，原则同意…… |
| 作出决定 | 会议决定……；会议同意…… |
| 提出要求 | 会议要求，……；会议强调，…… |
| 指出问题 | 会议指出，当前……仍然存在…… |
| 明确责任 | 由XX部牵头，XX部配合，于X月X日前完成 |
| 暂缓事项 | 会议认为该事项条件尚不成熟，责成XX部进一步论证后另行研究 |

### 3.3 禁止表述

- 不写"重要讲话""重要指示"（除非引用已公开的上级精神且表述准确）。
- 不写"一致认为""一致同意"，除非逐字稿明确无异议；有不同意见要如实反映。
- 不写"气氛热烈""畅所欲言""圆满成功"等新闻化、文学化表述。
- 不写"我们""大家""咱们"。
- 不添加逐字稿中没有的事实、数据、人名、单位、时间、文号。
- 不把建议写成决定，不把讨论写成决议。

## 4. 决策程序与"三重一大"

### 4.1 基本框架

国有企业重大事项决策遵循"三重一大"制度：**重大决策、重要人事任免、重大项目安排、大额资金运作**。党委（党组）对重大经营管理事项进行前置研究讨论，董事会、经理层按权限决策。

### 4.2 纪要中的写法

- 属于"三重一大"的事项：`会议同意……，按"三重一大"决策程序办理。` 或 `会议原则同意……，提请党委会前置研究后，按程序提交董事会审议。`
- 需要上级审批的：`会议同意……，按程序报集团公司审批。`
- 权限不明时：`会议同意……，具体按集团公司有关制度规定的权限和程序办理。`
- **不得编造**具体制度名称、文号、条款；需要引用时只写"按照集团公司有关制度规定"。

### 4.3 会议类型与权限提示

| 会议类型 | 常见权限 |
| --- | --- |
| 党委会 | 前置研究讨论重大经营管理事项、党的建设、干部人事 |
| 董事会 | 战略、投资、预算、重大合同、风险管控等法定职权 |
| 总经理办公会 | 生产经营执行事项、日常经营管理 |
| 专题会 | 专项事项研究，形成建议或落实要求 |
| 项目例会 | 进度、质量、安全、成本等现场事项 |

若逐字稿中的决定超出该会议类型常见权限，在纪要中写"按程序报批"，并在存疑提问中确认。

## 5. 存疑处理协议

成稿前必须检查以下六类信息；发现不确定，**先提问，不猜测**：

1. **人名与职务**：只有"张总""李局""王经理"等称呼，或姓名同音、职务不明。
2. **数字与金额**：投资额、合同额、面积、里程、比例、人数、工期，口语"三个亿""十来个"必须确认精确值。
3. **单位与项目名称**：简称、标段号、项目全称、分子公司名称。
4. **决定与分工**：是否形成决议、责任单位、责任人、完成时限。
5. **决策程序**：是否属于"三重一大"、是否需党委前置研究、是否需报上级审批。
6. **会议元信息**：时间、地点、主持人、参会人员、记录人缺失或矛盾。

提问要求：

- 一次最多 5 条，按影响程度排序；
- 每条必须引用逐字稿原文（≤60 字），说明"为什么必须确认"；
- 给出 2–4 个可选答案（能推断时），同时允许自由填写；
- 记录人选择"按逐字稿推定"时，纪要对应位置标注 `（待核）`，不得静默编造。

## 6. 责任分工写法

涉及落实事项，统一用表格：

| 序号 | 事项 | 责任单位 | 责任人 | 完成时限 |
| --- | --- | --- | --- | --- |
| 1 | …… | …… | …… | 2026年12月31日前 |

责任单位写规范全称或集团认可简称；责任人写姓名（职务）；时限写明确日期，不写"尽快""近期"。

## 7. 保密与合规

- 不写入涉密事项的具体密级、密码、部队番号、敏感地理坐标；涉及保密事项写"按保密规定办理"。
- 不写入个人身份证号、银行账号、家庭住址、健康状况等敏感个人信息。
- 不评价上级领导个人，不传播未经证实的消息。
- 涉及法律纠纷、事故调查的，只写会议部署，不写责任认定结论（除非会议已明确）。

## 8. 质量自检清单

输出前逐条检查：

1. 标题是否符合会议类型，是否去掉新闻化用语？
2. 七段式是否齐全（可选项除外）？
3. 会议时间、地点、主持人、参会人员是否完整，缺失是否标"（待补）"？
4. 每个议题是否有"听取—讨论—结论"三层？
5. 决定事项是否都有责任单位、责任人、时限？
6. 是否有把"听取"写成"同意"、把"建议"写成"决定"？
7. 数字、金额、单位、人名是否与逐字稿一致，不确定是否已标"（待核）"？
8. 是否出现逐字稿没有的事实、文号、制度名称？
9. "三重一大"事项是否注明决策程序？
10. 语言是否统一为"会议认为/强调/要求/决定"，是否残留口语？

## 9. 示例（节选）

```
# 中铁建工集团XX工程局2026年三季度安全生产工作会议纪要

**会议时间**：2026年10月23日（星期四）上午9:00
**会议地点**：局机关二楼会议室
**会议形式**：现场会议
**主持人**：张XX（总经理）
**参会人员**：李XX（副总经理）、王XX（安全总监）、各部门负责人
**记录人**：赵XX
**会议议题**：通报三季度安全生产情况，部署四季度安全重点工作

## 一、听取三季度安全生产工作情况汇报

会议听取了安全质量部关于2026年三季度安全生产工作的汇报。三季度全局共发生一般安全隐患XX项，整改完成率98.6%；未发生较大及以上生产安全事故。会议指出，部分项目存在危大工程方案执行不到位、分包队伍安全培训走过场等问题。

## 二、会议决定事项

1. 原则同意《四季度安全生产专项整治方案》，由安全质量部牵头，根据会议意见修改完善后，于2026年10月30日前印发实施。
2. 同意对XX项目、XX项目开展专项督导，由安全质量部、工程管理部组成督导组，于2026年11月15日前完成。
3. 会议要求，各单位主要负责人要亲自部署冬季施工安全防范工作，严防坍塌、火灾、触电事故。

## 三、会议要求

会议强调，四季度是全年安全生产的关键期，各单位要压实全员安全责任，坚决守住不发生较大及以上事故的底线。
```
